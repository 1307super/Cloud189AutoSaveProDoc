Casby 是当前版本新增的伪 Emby 能力模块。你可以把它理解成一套“围绕 TMDB 和资源绑定做管理”的媒体层，适合处理：

1. 电视剧 / 电影的海报墙管理
2. 以 TMDB 为主线的资源订阅
3. 多个分享源绑定到同一部作品
4. 剧集逐集绑定、电影文件绑定
5. Casby 内部用户与媒体库管理

## 一、Casby 适合什么场景

如果你遇到下面这些需求，Casby 很适合：

1. 我想先按 TMDB 订阅内容，再慢慢补资源源
2. 我想把同一部剧的多个来源绑定到同一个标题下
3. 我想手动修复剧集匹配错误
4. 我想按“媒体库”隔离电影、电视剧、动画等内容

## 二、进入 Casby 之前先准备什么

建议先具备以下条件：

1. 已经配置好 TMDB
2. 至少有一个可用的天翼账号
3. 如果要绑定分享源，手里要有分享链接或分享码

如果左侧菜单没有出现 `Casby`：

1. 先确认你使用的是新版本
2. 再确认当前环境是否启用了 Casby 功能开关

## 三、Casby 的整体工作流

最推荐的流程是：

1. 先创建媒体库
2. 再创建 Casby 用户
3. 从 TMDB 搜索并订阅资源
4. 为每个标题添加分享源
5. 进行自动或手动绑定
6. 后续按需同步元数据、补源、删季、删集

## 四、管理媒体库

入口：

1. 打开 `Casby`
2. 点击左侧 `管理媒体库`

### 新建媒体库时需要填写的常用项

| 字段 | 说明 |
| --- | --- |
| 名称 | 例如“电视剧”“电影”“动画剧集” |
| 类型 | 电影 / 电视剧 / 混合 |
| 启用状态 | 是否在主界面显示和使用 |
| 背景图 | 可选，用于页面展示 |
| 匹配规则 | 可选，用于自动匹配行为 |
| 排序 | 数字越小越靠前 |

### 推荐做法

1. 电影、电视剧尽量分开建库
2. 命名保持稳定，不要频繁改
3. 不想立刻使用的库可以先停用

## 五、管理 Casby 用户

入口：

1. 打开 `Casby`
2. 点击左侧 `管理账号`

### 可以做什么

1. 新建用户
2. 修改用户状态
3. 重置密码
4. 删除用户

### 新建用户步骤

1. 点击 `新建用户`
2. 填写用户名
3. 填写密码
4. 保存

### 编辑用户时

你可以：

1. 修改启用状态
2. 按需填写新密码

如果密码留空，通常表示不修改现有密码。

## 六、从 TMDB 订阅资源

每个媒体库都可以直接从 TMDB 搜索并订阅标题。

### 操作步骤

1. 在 Casby 主界面左侧选择目标媒体库
2. 在海报墙顶部点击 `新增订阅`
3. 输入片名或剧名
4. 点击搜索
5. 从结果中选择正确的电影或剧集
6. 点击订阅

订阅成功后，系统会自动建立标题，并同步：

1. 海报
2. 简介
3. 年份
4. 电影 / 电视剧类型
5. 对于电视剧，还会拉取季和集基础信息

## 七、查看和管理标题详情

在海报墙中点击任意标题，会打开详情弹窗。

详情页底部有 3 个最常用的操作：

1. `添加分享源`
2. `同步元数据`
3. `删除资源`

### 1. 同步元数据

适合场景：

1. TMDB 上的信息更新了
2. 你想手动刷新海报、简介、季集数据
3. 你怀疑初次订阅时没同步完整

### 2. 删除资源

会删除当前 Casby 标题记录。删除前请先确认是否还有绑定、来源或后续联动依赖它。

## 八、给标题添加分享源

详情页里的 `添加分享源` 支持两种方式。

### 方式一：手动输入

适合你已经有明确分享链接或分享码的情况。

步骤：

1. 打开标题详情
2. 点击 `添加分享源`
3. 在“方式一: 手动输入”里输入分享链接或分享码
4. 点击 `确定`

### 方式二：搜索资源

适合你还没有现成链接，想让系统先帮你搜资源。

步骤：

1. 打开标题详情
2. 点击 `添加分享源`
3. 在“方式二: 搜索资源”里输入关键词
4. 点击 `搜索`
5. 结果出来后：
   - 可以先点 `查看文件`
   - 确认没问题后勾选需要的资源
   - 点击 `添加选中的资源`

## 九、电视剧如何绑定到具体集

如果当前标题是电视剧，详情页会显示：

1. 季按钮
2. 当前季的集列表
3. 每一集的绑定状态

### 绑定一集的操作步骤

1. 进入某部剧的详情页
2. 选择目标季
3. 找到目标集
4. 点击该集右侧的 `绑定` 或 `添加源`
5. 在弹窗中选择分享源
6. 在文件列表中选择正确文件
7. 点击 `绑定`

### 多版本绑定

当前版本支持同一集绑定多个来源。

因此你会看到：

1. `已绑定`
2. `已绑定(2)`
3. 文件名摘要

这表示该集已经挂了多个源，而不是只能有一个文件。

## 十、电影如何绑定文件

电影没有季和集，详情页会直接显示 `电影绑定` 区块。

### 操作步骤

1. 打开电影详情
2. 点击 `绑定电影文件` 或 `添加源`
3. 选择分享源
4. 选择正确文件
5. 点击绑定

和电视剧一样，电影也支持追加多个来源。

## 十一、季和集的管理操作

电视剧详情页还支持管理动作。

### 1. 管理模式

点击 `管理` 后，可以进入批量管理状态。

可执行：

1. 全选 / 取消全选
2. 批量删除选中剧集

### 2. 启用 / 禁用季

在管理模式下，可对当前季执行：

1. 禁用
2. 启用

适合场景：

1. 某一季暂时不想参与匹配
2. 数据不完整，先暂停使用

### 3. 删除季

当某季数据明显错误，或者你想整体重建时，可以直接删除整季。

## 十二、Casby 的自动刷新行为

当前版本已经加入了连载剧元数据自动刷新能力。

大致效果是：

1. 对仍在更新中的剧集，系统会按计划刷新元数据
2. 减少你手动同步的频率
3. 更容易补到新播出的季集信息

这意味着你通常不需要频繁手动重建标题，只需要在异常时手动点一次 `同步元数据`。

## 十三、推荐使用方式

### 方式一：先订阅 TMDB，再补分享源

这是最推荐的 Casby 工作流：

1. 先建媒体库
2. 从 TMDB 搜索订阅
3. 再逐步补分享源
4. 对关键剧集手动校正绑定

优点：

1. 结构清晰
2. 标题和元数据更稳定
3. 后续维护成本低

### 方式二：先有资源，再用 Casby 做整理

如果你手里已经有很多分享源，也可以：

1. 先建立 TMDB 标题
2. 批量添加分享源
3. 再逐步绑定

## 十四、常见问题

### 1. 搜索到了 TMDB 结果，但没有资源，正常吗？

正常。TMDB 订阅负责建立“标题和元数据”，不是自动保证资源一定存在。你还需要继续添加分享源。

### 2. 为什么一集会显示多个绑定？

因为当前版本支持多版本绑定，同一集可以同时挂多个来源。

### 3. 什么时候要手动同步元数据？

适合以下情况：

1. 新季刚播出
2. 海报或简介没有刷新
3. 你怀疑标题信息没同步完整
