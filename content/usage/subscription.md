订阅中心用于管理“按用户订阅”的资源来源。它适合处理这类场景：

1. 你已经知道目标发布者的 UUID
2. 你希望持续跟踪某个订阅用户的资源
3. 你想把订阅资源直接转存成普通任务
4. 你想把订阅资源接到 STRM 的定时生成链路里

## 一、使用前准备

开始前请先确认：

1. 你已经在 `账号管理` 中添加了至少一个可用账号
2. 系统里有默认账号或至少一个可正常请求接口的账号
3. 你已经拿到目标用户的 UUID

## 二、添加订阅用户

### 操作步骤

1. 打开左侧菜单 `订阅中心`
2. 点击右上角 `添加订阅`
3. 在弹窗中输入目标用户的 UUID
4. 将输入框失焦，系统会自动预览用户信息
5. 在预览弹窗里确认用户名、头像、粉丝数等信息
6. 点击：
   - `确认添加`：当前账号已关注该用户时使用
   - `订阅并添加`：当前账号尚未关注该用户时使用

### 添加时系统会做什么

系统并不是只把 UUID 存下来，还会同时做这些动作：

1. 校验 UUID 是否有效
2. 读取该用户的基础信息
3. 检查当前默认账号是否已关注该用户
4. 如果未关注，则自动发起订阅
5. 尽量让所有可用账号都完成对该用户的关联

这样做的好处是，后续：

1. 资源读取更稳定
2. 订阅型 STRM 更容易直接工作
3. 多账号环境下更不容易出现“某个账号看不到资源”的问题

## 三、订阅列表中的常用操作

每个订阅卡片都支持以下操作：

### 1. 启用 / 停用

停用后，该订阅不会继续参与后续的资源拉取和订阅型 STRM 处理。

适合场景：

1. 先暂时停用一个源
2. 需要保留记录，但不想继续同步

### 2. 刷新

点击 `刷新` 后，系统会重新拉取：

1. 用户昵称
2. 头像
3. 关注状态
4. 各账号的关联情况

适合场景：

1. 目标用户改名了
2. 你怀疑部分账号没有成功关联
3. 新增了账号后，希望补一次关联

### 3. 删除

删除只会把该记录从系统订阅列表中移除，不建议把它理解为“取消天翼官方关注关系”。

删除前请确认：

1. 是否还有订阅型 STRM 配置正在引用这个订阅用户
2. 是否还有正在使用该订阅资源创建的任务

## 四、查看订阅资源

在订阅卡片中，点击用户名即可进入资源列表。

### 资源列表支持的能力

1. 查看根目录资源
2. 进入文件夹继续浏览
3. 使用关键字搜索文件名
4. 对单个资源直接点击 `转存`

### 浏览方式

如果你点击的是文件夹：

1. 系统会进入文件夹内部
2. 顶部会出现面包屑导航
3. 你可以随时返回上一级或回到根目录

### 搜索方式

在资源列表弹窗顶部输入关键字后：

1. 根目录下会按资源名筛选
2. 文件夹内部也支持按文件名搜索
3. 清空搜索词后会恢复完整列表

## 五、从订阅资源直接创建转存任务

资源列表中的每个条目都带有 `转存` 按钮。

### 操作流程

1. 打开某个订阅用户的资源列表
2. 找到要转存的文件或文件夹
3. 点击右侧 `转存`
4. 系统会自动打开 `创建任务` 弹窗，并预填分享链接信息
5. 你继续选择：
   - 转存账号
   - 转存目录
   - 任务分组
   - 玄鲸直连 / AI识别 / 正则等
6. 点击保存

### 适合什么时候这样用

1. 你只想转存订阅中的某一部资源
2. 你不想先创建整套订阅型 STRM 配置
3. 你更习惯按资源逐个确认

## 六、和 STRM 的联动方式

订阅中心与 STRM 的配合是当前版本的重要能力。

### 使用步骤

1. 先在 `订阅中心` 添加目标用户
2. 再进入左侧菜单 `STRM`
3. 新建配置时选择 `订阅` 类型
4. 选择订阅用户
5. 再决定是否只选部分资源
6. 保存后即可手动生成或配置定时任务

### 两种常见用法

#### 用法一：处理整个订阅用户

不额外选择具体资源，系统默认处理该订阅用户下的全部根目录资源。

适合：

1. 订阅源比较稳定
2. 你希望完整同步该用户内容

#### 用法二：只处理指定资源

在 STRM 配置中点击 `选择资源`，只勾选你要的目录或资源。

适合：

1. 只想同步其中几部剧
2. 不想把该用户的全部资源都接入 STRM

详细说明请继续查看：[STRM 使用说明](/Cloud189AutoSaveProDoc/usage/strm/)

## 七、推荐工作流

### 如果你的目标是“只转存”

1. 添加订阅用户
2. 打开资源列表
3. 找到目标资源
4. 点击 `转存`
5. 用普通任务管理

### 如果你的目标是“持续生成 STRM”

1. 添加订阅用户
2. 测试能否正常读取资源
3. 去 `STRM` 页面创建订阅型配置
4. 视情况开启定时任务
5. 持续观察增量更新情况

## 八、常见问题

### 1. 输入 UUID 后为什么要先预览？

因为系统需要先确认：

1. UUID 是否有效
2. 用户信息是否正确
3. 当前账号是否已经关注该用户

这一步能减少错误添加。

### 2. 为什么添加订阅时会提示“自动订阅”？

因为该用户当前还没有被系统账号关注。为了保证后续资源读取和同步稳定，系统会自动补做关注动作。

### 3. 停用订阅后还能不能在 STRM 中使用？

不建议。订阅型 STRM 依赖订阅记录处于启用状态，停用后可能无法正常拉取资源。
