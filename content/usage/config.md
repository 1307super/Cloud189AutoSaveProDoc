本页主要说明 `媒体设置` 与 `系统设置` 里的常用配置项。对于操作链路比较长的功能，例如订阅中心、STRM、Casby、反代，本页只说明配置入口和核心作用，详细使用方法请分别查看对应专题文档。

## 一、媒体设置

媒体设置主要负责播放、刮削、反代、搜索和命名相关能力。

### 1. OpenAI

入口：`媒体 -> OpenAI`

常用字段如下：

| 字段 | 说明 |
| --- | --- |
| 启用 AI | 总开关，不开时系统不会调用 AI 服务 |
| 启用智能识别 | 在本地启发式规则基础上，让 AI 做增强纠偏 |
| API 地址 | OpenAI 兼容接口地址 |
| API Key | 调用密钥 |
| AI 模型 | 例如 GLM / GPT / 其他兼容模型 |
| 剧集命名模板 | 控制电视剧文件命名格式 |
| 电影命名模板 | 控制电影文件命名格式 |

建议：

1. 先保证接口能正常调用，再开启智能识别。
2. 模板尽量保持稳定，不要频繁修改。
3. 对于已有大量任务的环境，修改模板前先做小范围测试。

详细说明请查看：[AI辅助](/Cloud189AutoSaveProDoc/advanced/ai/)

### 2. STRM

入口：`媒体 -> STRM`

全局设置：

| 字段 | 说明 |
| --- | --- |
| 启用生成 | STRM 功能总开关 |
| 排除根目录 | 兼容旧版路径结构时可开启 |
| 自动删除 | 当资源失效时，允许系统自动清理对应 STRM 文件 |

这里只是全局开关。真正的目录选择、订阅型 STRM、Cron 定时、增量更新等操作，统一在 `STRM` 独立菜单中完成。

详细说明请查看：[STRM 使用说明](/Cloud189AutoSaveProDoc/usage/strm/)

### 3. 飞牛反代

入口：`媒体 -> 飞牛反代`

可配置项：

| 字段 | 说明 |
| --- | --- |
| 启用反代 | 开启飞牛反代能力 |
| 飞牛服务地址 | 飞牛服务的访问地址，例如 `http://192.168.1.100:8005` |
| 自动删除失效资源 | 发现失效条目后，自动尝试清理对应资源 |

重要说明：

1. 修改飞牛反代参数后，需要重启容器才会生效。
2. 如果你是在非飞牛影视客户端里使用飞牛 302 反代，需要额外挂载飞牛媒体库目录，并确保容器内外路径完全一致。

详细说明请查看：[反代配置](/Cloud189AutoSaveProDoc/usage/proxy/)

### 4. Emby

入口：`媒体 -> Emby`

常用字段：

| 字段 | 说明 |
| --- | --- |
| 启用 Emby | 是否启用 Emby 相关能力 |
| 服务器地址 | Emby 地址，例如 `http://emby:8096` |
| API Key | Emby API Key |
| 路径替换 | 用于把任务或 STRM 路径映射成 Emby 媒体库路径 |

适用场景：

1. 任务完成后通知 Emby 扫库
2. 路径与 Emby 媒体库不一致时做路径替换

### 5. TMDB

入口：`媒体 -> TMDB`

常用字段：

| 字段 | 说明 |
| --- | --- |
| 启用 TMDB | 总开关 |
| 启用刮削 | 是否启用 TMDB 元数据刮削 |
| API Key | TMDB API 密钥 |

启用 TMDB 后，系统可用于：

1. 任务创建时关联 TMDB
2. 海报墙和元数据展示
3. Casby 中的 TMDB 订阅和资源匹配

### 6. CloudSaver / PanSou

入口：

1. `媒体 -> CloudSaver`
2. `媒体 -> PanSou`

这些功能用于外部资源检索与辅助导入。若要使用，请先确认服务本身已经可用，再回到系统填写地址、用户名和密码。

### 7. 正则预设

入口：`媒体 -> 正则预设`

适合把常用的：

1. 文件筛选规则
2. 文件重命名规则
3. 备注说明

统一保存成预设，后续在创建任务时可以直接复用。

## 二、系统设置

系统设置主要负责任务执行策略和运行行为。

入口：`系统 -> 任务设置`

### 1. 任务检查设置

| 字段 | 说明 |
| --- | --- |
| 任务过期天数 | 任务超过这个天数后会进入过期判断 |
| 最大重试次数 | 单个任务失败后的最大重试次数 |
| 重试间隔 | 两次重试之间的等待时间 |
| 任务检查定时 | 系统批量检查任务状态的 Cron 表达式 |

### 2. 文件类型设置

| 字段 | 说明 |
| --- | --- |
| 媒体文件后缀 | 哪些后缀被视为媒体文件 |
| 元数据文件后缀 | 哪些后缀被视为字幕、NFO 等元数据 |
| 仅转存指定后缀 | 开启后，非目标后缀文件会被过滤 |
| 云盘文件夹不存在时自动创建 | 目标目录不存在时自动补建 |

### 3. 高级设置

| 字段 | 说明 |
| --- | --- |
| 自动清空个人回收站 | 按定时规则自动清空个人回收站 |
| 自动清空家庭回收站 | 按定时规则自动清空家庭回收站 |
| 清空回收站定时 | 回收站清理使用的 Cron |
| 并发数量 | 任务执行并发数 |
| 同名目录合并 | 处理资源时自动合并同名目录 |
| 等待队列 | 对需要审核或延迟可见的资源启用等待队列 |
| 玄鲸直连 | 新建任务时默认开启玄鲸直连 |

## 三、配置修改后的生效规则

1. 大多数设置修改后，点击 `保存` 即可生效。
2. 飞牛反代配置修改后，需要重启容器。
3. 已经创建好的任务，不一定会自动继承新的默认值；必要时请编辑任务或重建配置。
4. 已经存在的 STRM、媒体库绑定、路径映射，也不会因为改了全局配置就自动全部重算。

## 四、推荐配置顺序

如果你是首次部署，推荐按下面的顺序配置：

1. 先在 `账号管理` 中添加可用账号
2. 再在 `媒体设置` 中配置 TMDB、OpenAI、Emby
3. 根据需要开启 `STRM` 和 `飞牛反代`
4. 最后在 `系统设置` 中补并发、任务检查、文件后缀等细项
